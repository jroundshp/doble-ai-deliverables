Product Schema Plugin

One small WordPress plugin covering all 24 product pages. Nothing to configure, and nothing a visitor sees changes.

Download the plugin vpc-product-schema-plugin.zip · 10 KB · version 1.2.1 · 21 September 2026

What it does

Your product pages already list the specifications in a table a person can read and a machine cannot: footprint, deck height, capacity, feature count. The plugin republishes those same numbers in the format Google and the AI assistants parse. It adds nothing that is not already written on the page.

Version 1.2.1 corrects five specifications to match the pages and the current data sheets (Cannon, Power Plunge, Rain Maker, Triple Buzz and Thump Pump) and carries the tidied Waterfall Model 200, 300 and 400 answers. Like 1.2, it covers all 24 product pages: the 9 aquatic play structures and the 15 water play features. On the 9 structure pages it also marks up the three questions in the “Got Questions?” panel, word for word as they appear on the page.

Installing it

  1. In WordPress, go to Plugins → Add New → Upload Plugin.
  2. Choose the zip above. Click Install Now, then Activate.
  3. If version 1.1 or 1.2 is already installed, WordPress offers Replace current with uploaded. Choose it.
  4. If the site uses a page cache, clear it so the pages pick up the new version.
  5. Open validator.schema.org and paste in any product page address.

A structure page such as /products/aquatic-play-structures/misty-island-100/ shows a Product and an FAQPage. A water play feature page such as /products/water-play-features/jet-stream/ shows a Product. Deactivating removes everything the plugin adds.

One thing worth knowing

The plugin keeps a copy of each page’s figures and FAQ text. If a spec or an FAQ answer is edited on a page later, the matching line in the plugin needs the same edit, because Google expects the marked-up questions to match what a visitor sees. The README inside the zip shows where.
