Product Schema Plugin

One small WordPress plugin. Nothing to configure, and nothing a visitor sees changes.

Download the plugin vpc-product-schema-plugin.zip · 5 KB · version 1.1

What it does

Your product pages already list the specifications in a table a person can read and a machine cannot: footprint, deck height, capacity, feature count. The plugin republishes those same numbers in the format Google and the AI assistants parse. It adds nothing that is not already written on the page.

Installing it

  1. In WordPress, go to Plugins → Add New → Upload Plugin.
  2. Choose the zip above. Click Install Now, then Activate.
  3. Open Google’s Rich Results Test on /products/aquatic-play-structures/triwave-100/.

Only the TriWave 100 is filled in, so activating changes exactly one URL. Before, no product detected. After, a product carrying nine specifications. Deactivating puts it back. The other 23 are copies of that same block with their own numbers, and we will fill those in.

One thing worth knowing

The play site now publishes a company record in its markup, logo and all, which it did not in early September. The plugin references that record rather than publishing its own. While you are in Yoast, that record is missing three fields: the street address, the phone number, and the link up to VPC as the parent company. They are on Yoast’s settings screen rather than in any file.
