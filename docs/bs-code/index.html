How to add each block

  1. Open the page (About or Menu) with Edit with Elementor.
  2. Drag an HTML widget onto the page. The bottom of the page is fine; it shows nothing to visitors.
  3. Click Copy code below and paste the whole block into the widget, including the first and last lines.
  4. Click Update, then clear the LiteSpeed cache.
  5. To check it: paste the page address into validator.schema.org. The About page should show an FAQPage with 9 questions; the Menu page should show a Menu with 25 items.

One thing to keep in mind. The code is a copy of what the page says today. If a question, answer or price changes on the page, change it in the code too, so the two always match. Morning Buns are $4.50 here because that is what the Menu page shows; if Toast’s $5.00 is the current price, update both.
