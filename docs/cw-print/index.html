Before you order

  • Send the printer the PDF. It's the exact print size with the bleed already in, and the text has been converted to shapes, so the printer's fonts can't change how it looks. The PNG is a backup copy of the same design.
  • Magnets: 30 mil magnetic vinyl is the standard thickness for highway use, and thinner ones peel off. Check that the doors are steel, because magnets won't hold on aluminum or composite panels. If a truck has aluminum doors, the same file prints as a stick-on vinyl decal.
  • No USDOT number on the magnets. This is on purpose, because nobody has confirmed which number belongs on these trucks. Patriot's 4232633 is registered to the Texas company. When the right number is confirmed, send it and I'll add the line.
  • Signs: for outdoors, ask for aluminum composite (Dibond or similar) with a UV laminate. There's clear space around the edge for grommets at every size.
  • Colors: ask for a proof before the full run. Watch the yellow most closely, because it's the color most likely to print green or orange. Charcoal #1E272B, yellow #F2B532, amber #C2870C for the ".com" on the cream versions, cream #FAF7F3.
