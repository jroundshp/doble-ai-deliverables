03
Still to do: the Bake Shop

Items 01 and 02 go together and are worth more than everything else on this list. Both are switches on one Yoast screen.

01
Turn Portfolio on in search Bake Shop
The four portfolio pages are set to show individually, but Yoast leaves a whole content type out of the sitemap while the type-level switch is off. So Google still isn't told about them: cpt_portfolio-sitemap.xml returns a 404 today.
  1. Yoast SEO › Settings › Content types › Portfolio
  2. Switch "Show portfolio in search results" on, then save
  3. Check ellicottvillebakeshop.com/cpt_portfolio-sitemap.xml: the 404 should become a list of four pages. Catering keeps its own hidden setting.
02
Turn Theme Layouts off in search Bake Shop
Eight of the theme's internal building blocks (slide-1, slide-2, header and footer layouts, a popup) are live, indexable pages, and the sitemap hands them to Google. Yoast's own help text under the switch explains that turning it off also takes them out of the sitemap.
  1. Same screen, Content types › Theme Layouts
  2. Switch "Show theme layouts in search results" off, then save
  3. The sitemap index also lists three small "group" sitemaps from the theme. They're thin and worth switching off the same way if they appear on that screen.
03
Fix the homepage share image Bake Shop
The homepage sends two share images. The first is cookie-butter-cinnamon-bun.jpg, which no longer exists. The second is the 209×80 logo, which is below Facebook's minimum size. The result is that a shared homepage link shows no picture.
  1. Edit the Home page › Yoast SEO panel › Social tab
  2. Set the Facebook and X image to Cookie Butter Bun from the media library
  3. Paste the homepage into Facebook's Sharing Debugger and click Scrape Again
04

The same address is in the Bakery record and in Yoast's publisher setting. We need the working page address from whoever runs the Bake Shop's Facebook, and then all three places can be updated.

Alpine links to the Bake Shop from all six of its pages. The Bake Shop doesn't link back, and the word "Alpine" appears nowhere on its homepage, About, Menu, Contact or Catering page. It's also the one most likely to send an actual customer across the street.

The homepage still has three main headings, and two of them are slide captions. In Elementor, open the Slide 1 and Slide 2 layouts, select each title and set its HTML tag to H2. The captions will look exactly the same.

Turn off author archives Bake Shop
/author/admin/, /author/dobleai/ and an author page for Amanda's account all load as public pages, which publishes login names. Yoast SEO › Settings › Advanced › Author archives, switch off.
10
Verify the site with Bing, after 01 and 02 Bake Shop
Bing's index feeds Microsoft Copilot, DuckDuckGo and Yahoo, and it's one of the sources ChatGPT search draws on. Sign in at bing.com/webmasters, use Import from Google Search Console if the site is there, or paste the meta tag code into Yoast SEO › Settings › Site connections › Bing. Then submit sitemap_index.xml. Do this after items 01 and 02, because submitting today's sitemap would send Bing the theme scaffolding and none of the portfolio pages.
