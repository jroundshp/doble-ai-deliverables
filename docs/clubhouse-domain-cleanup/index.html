The pattern in the four items

Each one is a place where the live Clubhouse site still reaches back to the retired domain. That is the opposite of the usual leftover, where the dead site keeps pointing at itself. It matters because the retired domain belongs to a business that is closed, and the natural next step with a closed business's domain is to stop paying for it.

rookiescrafthouseny.com is registered through December 19, 2026. If it lapses, the items below stop being tidiness and start being outages.

The four items

1

The ORDER ONLINE button in the main menu points at the closed brand's domain

15 minutes One menu item Fully reversible
What we found

The ORDER ONLINE item in the main navigation is a custom menu link pointing to https://rookiescrafthouseny.com/contact/. It sits in the header of all seven pages, so it is on every page of the site.

Following it lands on the Clubhouse contact page served from the retired domain. That page has a phone number, an email address and an address on it. It has no online ordering of any kind. The only occurrence of the phrase "order online" anywhere on it is the navigation item that sent you there.

In total the live site carries 15 links to the retired domain across the seven pages. This is the one that appears on every one of them.

Why it's important to change

Of everything in this document, this is the one costing money today rather than eventually. A guest who wants to order food clicks the button labelled to let them do it, and arrives at a page that cannot take their order. That is a lost sale in the moment, with no error message to explain it and no reason for the guest to try again.

The domain question sits underneath it. Even once the ordering destination is right, a header link on every page routed through a closed business's domain is one renewal notice away from being a broken button.

How to verify it
  1. Open https://www.cooperstownclubhouse.com/ in a private browsing window. Hover over ORDER ONLINE in the header and read the destination in the status bar at the bottom of the browser. It reads rookiescrafthouseny.com.
  2. Click it and read the page you land on. Confirm for yourself whether anything on it can take an order.
  3. Check the header on the other pages, MENU, TEAMS, CONTACT, ACTIVITIES, CAREERS, BAR MENU. The same link is in all of them.
The steps
  1. In WordPress go to Appearance → Menus and select the main header menu.
  2. Find the ORDER ONLINE entry. It is a Custom Link, so it has a URL field you can edit directly.
  3. Decide what it should point to. If there is a real ordering system, that URL. If ordering is by phone right now, the honest fix is to relabel it, ORDER BY PHONE with a tel: link, or remove it and let CONTACT do the work.
  4. If it should stay pointed at the contact page for now, at minimum change the domain to https://www.cooperstownclubhouse.com/contact/ so it no longer travels through the retired domain.
  5. Save, then load the live homepage in a private window and hover the link again to confirm.
2

21 images on the live site are loaded from the retired domain

20 minutes Find and replace Reversible with a backup
What we found

Across the seven live pages, 21 distinct image files are referenced at addresses beginning http://rookiescrafthouseny.com/wp-content/uploads/. They include the team parties photo, the burger and beer sketches, the bartender shot, the cornhole photo and the section divider textures.

Two details make this straightforward to fix. They are referenced over plain http rather than https. And the identical files already exist on the Clubhouse domain at the same paths, so nothing needs re-uploading. We checked one directly: /wp-content/uploads/2023/12/burger-300x300.png returns the image on both domains.

They display correctly today. This is not a visible fault on the site right now.

Why it's important to change

Because it is a dependency on a domain the business has retired, and it is invisible until the day it isn't. The registration runs to 19 December 2026. If nobody renews it, and there is no obvious reason to keep renewing a closed restaurant's domain, 21 images across the live site turn into broken image icons on the same day. Nothing in WordPress will warn anyone first.

The http prefix is the smaller half. A secure page pulling images over an insecure connection is untidy, and browsers handle it inconsistently. Since the files are already sitting on the right domain, both halves are fixed by the same edit.

How to verify it
  1. Open the live homepage, right-click and choose View Page Source, then search the page for rookiescrafthouseny.com/wp-content. The matches are the image references.
  2. Or open the homepage, press F12 for developer tools, go to the Network tab, filter to Img and reload. The domain each image comes from is listed per row.
  3. To confirm the replacement will work before making it, open https://www.cooperstownclubhouse.com/wp-content/uploads/2023/12/burger-300x300.png in a tab. The image loads, which is what makes this a find-and-replace rather than a re-upload.
The steps
  1. Take a database backup first. This is a bulk edit and that is the one thing that makes it safely reversible.
  2. Install Better Search Replace, a free plugin, or use the equivalent tool your host provides.
  3. Run it with search http://rookiescrafthouseny.com/wp-content and replace https://www.cooperstownclubhouse.com/wp-content, across all tables, with Run as dry run ticked first so you can see the count before anything changes.
  4. If the dry run count looks sane, untick it and run it for real.
  5. Repeat with https://rookiescrafthouseny.com/wp-content in case any references use the secure prefix.
  6. Clear any caching plugin and your CDN, then reload each of the seven pages and confirm the images still appear.

3

Only the homepage of the retired domain redirects. The interior pages still load.

10 minutes One rule Fully reversible
What we found

The root of the retired domain redirects correctly. The pages beneath it do not. Each returns a full page with a 200 response instead of forwarding to its Clubhouse equivalent.

Each of those pages does carry a canonical tag naming the Clubhouse version, which is a sensible backstop and is presumably why it was left this way. It is a reasonable choice rather than an oversight.

Why it's important to change

A canonical tag is a hint. A 301 is an instruction. Search engines usually honour a canonical, but they are free to disregard it, and nothing else does anything with it at all. A person following an old link, a bookmark, a printed flyer or a link from another site simply arrives on the retired domain and stays there.

What that person sees is the current Clubhouse content under the old brand's web address, with no sign anything has changed. If they bookmark it or pass it on, the retired domain keeps circulating. And the same expiry risk applies. When the domain lapses those pages disappear rather than forwarding.

How to verify it
  1. In a private browsing window, open https://www.rookiescrafthouseny.com/menu/. Watch the address bar. It stays on the retired domain rather than moving to cooperstownclubhouse.com, and a full menu page loads.
  2. Compare with https://www.rookiescrafthouseny.com/, which does move to the Clubhouse address. That contrast is the whole finding.
  3. To see the canonical backstop, View Page Source on the menu page and search for canonical. It names the Clubhouse URL.
The steps

The aim is for every address on the retired domain to forward to the matching address on the live one, rather than only the homepage.

  • If the redirect is currently set in the retired site's .htaccess, the rule below replaces a homepage-only redirect with one that carries the path across. Whoever manages the hosting will recognise it.
  • If it was set with a plugin or a hosting control-panel redirect, the same change is usually a checkbox worded something like forward with path or wildcard redirect, rather than redirect to homepage.
  • Test afterwards with /menu/ and confirm the address bar lands on cooperstownclubhouse.com/menu/, not on the Clubhouse homepage. Landing everyone on the homepage regardless of what they asked for is the common way this gets done, and it is worse than what is there now.
Path-preserving redirect for .htaccess on the retired domain
RewriteEngine On
RewriteCond %{HTTP_HOST} ^(www\.)?rookiescrafthouseny\.com$ [NC]
RewriteRule ^(.*)$ https://www.cooperstownclubhouse.com/$1 [R=301,L]

One caveat worth handling in the same sitting. If item 2 has not been done yet, a blanket redirect will also catch the /wp-content/uploads/ image addresses the live site is still using. Do item 2 first, or exclude that path, or the images will start redirecting instead of loading.

The email icon on the contact page writes to a different address than the one printed beside it

5 minutes One field Fully reversible
What we found

On the contact page there is an envelope icon with the email address printed directly underneath it. They do not go to the same place.

The printed address, and the link on that text, is restaurant@cooperstownexperience.com. The envelope icon immediately above it is a separate link that opens a message to rookies4850@gmail.com, the closed brand's address. Clicking the icon and clicking the words below it produce two different recipients.

The address appears on all seven pages, since the block is in the shared template.

Why it's important to change

Whether this costs anything depends on one fact we cannot see from outside: whether anyone still reads rookies4850@gmail.com. If that inbox is monitored, this is untidy. If it is not, every guest who clicks the icon rather than the text is writing to a mailbox nobody opens, and getting no reply to what may be a party booking enquiry. They will not know their message went nowhere and neither will you.

It is also the only place on the live site still carrying the closed brand's name in something a guest can act on.

How to verify it
  1. Open https://www.cooperstownclubhouse.com/contact/. Hover over the envelope icon and read the address in the status bar at the bottom of the browser. Then hover over the email text just below it. The two differ.
  2. If the status bar is awkward to read, right-click the icon, copy the link address, and paste it somewhere. It reads mailto:rookies4850@gmail.com.
  3. The separate question is worth answering while you are there: sign in to rookies4850@gmail.com, or ask whoever holds it, and see whether anything has arrived recently and gone unanswered.
The steps
  1. Edit the contact page in Divi and select the envelope icon module sitting above the email text. It is an Icon module, not the text one.
  2. Under Content → Link, its Module Link URL is mailto:rookies4850@gmail.com. Change it to mailto:restaurant@cooperstownexperience.com so it matches the text below it.
  3. Save, then reload the live page and hover both to confirm they now agree.
  4. Separately, if that Gmail account is going to be retired, set an auto-forward from it to the address you are keeping before you stop watching it. Anything already sent there is otherwise lost quietly.
