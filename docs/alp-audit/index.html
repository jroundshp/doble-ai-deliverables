Beyond the website

These don't count toward the score. They are still worth doing, and the first one is worth doing today.

To fix

  • Instagram's "Book an Event!" link is broken: it points to alpinebistrony.com/events, with an s. The hosting server forwards that address to a page on another site that no longer exists, so anyone who taps it from Instagram sees "404 Not Found." The real events page is alpinebistrony.com/event/. Fix: in the Instagram profile, edit the links and change "Book an Event!" to https://alpinebistrony.com/event/. The redirect on the hosting server is worth removing too, by whoever manages the hosting account.

Worth a look

  • Analytics: no Google Analytics tag is on any page, so there's no record of how many people visit or which pages they use. Setting it up takes a few minutes once there's a Google Analytics property to connect.
  • Search Console access: our reporting account can't read Alpine's Search Console yet. Adding ga4-reader@doble-ai-analytics.iam.gserviceaccount.com with Full permission would let us confirm how Google indexes each page and whether the sitemap was accepted.
  • Google profile: 4.6 stars from 74 reviews, listed as a Bistro with the right address, phone, website and all seven days of hours.
