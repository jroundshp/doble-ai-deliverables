Set each engine up properly, because "use a private window" is only correct for two of the four.

Google and Perplexity: an incognito window is the right control. It drops your account and your search history. On Google it will not change your location, which it reads from your internet connection, so results still reflect where the browser physically is.

ChatGPT: incognito will not do it. ChatGPT's Memory is attached to the account rather than the browser, it is switched on by default, and a private window does not touch it. Use Temporary Chat instead, the mode that ignores memory and history entirely. If you are signed in, also open Settings and read what Memory has stored about the business, which is worth knowing in its own right.

Grok: it requires a sign-in, so incognito only produces a login screen. Sign in and start a brand new conversation rather than continuing an existing thread, since an open thread carries its own context.

Have five different people run it, not one. These systems are not deterministic. The same question asked twice can name different businesses, so one person running it once is a sample of one and can mislead in either direction. Five people means five different accounts, histories and connections, and what comes back is the range rather than a single reading.

Keep it comparable. Use the prompts word for word, since rephrasing changes the answer. Same order, same day. Screenshot every answer, including the sources or citations panel where the engine shows one, because who gets cited matters as much as who gets named. Put everything in one shared folder labelled by person and engine. If everyone is on the same office connection, Google sees one location for all of them, which is fine as long as you know it.

Re-run the identical set monthly. The movement in those answers is the scoreboard for the rest of the work.
